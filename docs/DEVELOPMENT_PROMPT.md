아래 이전 프롬프트보다 최신 요청을 우선합니다. 로그인 음식 클릭 추천을 제거하고 음식점은 카카오맵 장소 검색의 실제 정보로 연결합니다. 사진·별점 제공 없음 표시와 카카오 상세·외부 검색 링크를 사용합니다. 예시 음식점·영상·구글 본문은 화면에서 제거하며 이전 저장 데이터는 보존합니다. 테스트는 TEST_PLAN.md에서 별도 관리합니다. 지역명과 가게 이름으로 실제 유튜브 영상 썸네일을 최대 5개 조회하고 클릭 재생을 연결합니다. 자연어·AI·여행 루트는 후속 기획입니다.

## 지금 요청할 기본 코드 프롬프트

```text
EnjoyTrip 프론트엔드의 기본 코드를 작성해줘.

기준:
- 제공된 EnjoyTrip Web(Front) 명세서를 참고하되, 최신 사용자 요청을 우선해.
- HTML5, CSS3, Vanilla JavaScript와 Bootstrap 기본 요소를 사용해.
- 디자인 작업 없이 기능 확인용 폼, 목록, 상세 화면만 만들어.
- 기존 01_api 예제와 resources는 보존해.

이번 구현 범위:
1. F101: 한국관광공사 지역별 관광정보 조회.
2. F102: 관광지, 숙박, 음식점 유형별 조회.
3. F103: 문화시설, 공연/행사, 여행코스, 쇼핑 유형별 조회.
4. F107: 회원가입, 회원정보 조회, 수정, 탈퇴.
5. F108: 로그인, 로그아웃, 비밀번호 찾기 흐름.

구현 방식:
- 프론트엔드 실습이므로 회원 데이터는 localStorage로 관리해.
- 실제 인증 서버나 메일 발송이 없는 비밀번호 재설정은 데모라고 표시해.
- API 키 없이도 샘플 데이터로 기본 화면과 기능을 확인할 수 있게 해.
- 실제 API 모드를 별도로 제공하고, 실패 시 샘플을 실제 데이터처럼 표시하지 마.
- API 비밀 키는 커밋하지 않고 로컬 실행용 중계 서버의 환경변수로 읽어.
- 빈 결과, 로딩, 오류, 폼 유효성 검사와 실행 방법을 포함해.

이번에 구현하지 않을 기능:
- 자연어 맛집 추천, AI 연동, 유튜브/블로그 인사이트.
- 음식점 선택, 여행 루트 생성/저장, 게시판, hotplace 등록.

문서:
- README에 실행 방법, 필수 기능 대응표, 샘플/실제 API 구분과 한계를 적어.
- 프로젝트 기획은 별도 Markdown에 정리해.
```

## 이후 맛집 여행 기능을 구현할 때 사용할 프롬프트

아래는 기획을 다음 단계로 확장할 때 사용하는 프롬프트다. **현재 코드에 이 기능을 구현하라는 요청이 아니다.**

```text
기존 EnjoyTrip 기본 코드를 확장해서 1일짜리 맛집 여행 프로젝트를 구현해줘.

서비스 목표:
유저가 자연어로 여행 컨셉을 입력하면 관련 맛집을 추천하고,
영상과 여러 리뷰를 직접 확인할 수 있게 인사이트를 제공해.
유저가 고른 음식점을 기준으로 방문 순서를 구성하고 여행을 저장하게 해.

핵심 흐름:
자연어 컨셉 입력 → 조건 확인 → 맛집 추천 → 인사이트 탐색
→ 음식점 선택 → 방문 순서 구성/편집 → 여행 저장/재조회.

요구사항:
1. 자연어에서 지역, 음식 취향, 동행, 분위기, 예산을 추출해.
   없는 조건은 추측하지 말고 해석한 조건을 유저에게 보여줘.
2. 실제 확보한 음식점 후보 안에서 추천하고, 추천 이유와 데이터 출처를 표시해.
3. 카카오 Local API가 리뷰/별점을 제공한다고 가정하지 마.
   초기에는 장소 상세 리뷰 링크와 실제 확보한 정보로 구성해.
4. 음식점 이름과 지역으로 YouTube 영상을 검색해서 가로 목록으로 보여줘.
   검색 결과를 실제 방문 인증이나 긍정적인 리뷰로 단정하지 마.
   영상이 없거나 API 연결이 안 되면 빈 상태와 검색 링크를 제공해.
5. 카카오맵, 블로그, 구글 등 다른 리뷰를 찾을 링크를 제공해.
6. 음식점을 여행 목록에 추가/삭제하고, 방문 순서를 수정할 수 있게 해.
7. 선택 음식점 좌표를 이용해 방문 순서를 제안해.
   실제 길찾기 API를 쓰지 않았다면 도로거리/소요시간을 표시하지 마.
8. 여행 이름, 음식점, 방문 순서를 저장하고 다시 열 수 있게 해.
9. 기존 명세서 필수 기능은 유지해.

우선순위:
- 먼저 전체 유저 흐름을 완성해.
- AI·영상·길찾기 연결은 각각 교체 가능한 서비스 모듈로 구성해.
- 샘플, 실제 API 응답, AI 추론을 구분해서 보여줘.
- 리뷰, 영상, 별점, 음식점 정보를 만들어내지 마.
- 디자인 수준은 별도 요청을 따르고, 새로운 기능을 임의로 늘리지 마.

완료 기준:
유저가 컨셉을 입력하고 후보의 근거를 확인한 뒤,
음식점을 선택하고 순서를 바꾸어 저장한 여행을 다시 열 수 있다.
```
