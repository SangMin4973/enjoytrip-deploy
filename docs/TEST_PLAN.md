# 맛집기행 테스트 단계

화면 구현 설명과 분리한 확인 절차입니다. 테스트 결과는 실제 확인 후 아래에 기록합니다.

## 1. 자동 검사

프로젝트 폴더에서 실행합니다. 실제 브라우저 계정이나 북마크를 사용하지 않는 독립 검사입니다.

```powershell
npm test
```

이번 음식점·북마크·마이페이지 확인만 실행하려면 다음 명령을 사용합니다.

```powershell
node --test tests/restaurant-flow.test.js
```

## 2. 화면과 이동 확인

```powershell
npm start -- --port=5179
```

http://127.0.0.1:5179/ 를 같은 브라우저에서 엽니다. 실제 회원과 분리해 확인하려면 별도의 브라우저 프로필을 사용합니다.

1. 새 계정으로 가입하고 로그인합니다. 로그인 직후 가운데 지역·메뉴 검색 창이 보이는지 확인합니다.
2. 광주만 입력해 검색합니다. 목록에 6곳, 상단에 광주, 우측에 선명한 지도가 보여야 합니다.
3. 광주·치킨을 입력해 검색합니다. 목록 1곳과 상단의 검색 내용, 사진 자리·이름·전화·위치·예시 별점을 확인합니다.
4. 음식점을 클릭합니다. 기존 목록과 스크롤 위치를 유지한 채 인사이트가 옆으로 열려야 합니다.
5. 네이버 검색 → 예시 영상 4개(최대 5개) → 유튜브 검색 → 구글 내용 예시 → 구글 검색 순서를 확인합니다.
6. 영상 한 개를 누르고 닫습니다. 유튜브 보기 창이 열리고 닫을 때 재생이 종료되는지 확인합니다. 영상 제공자의 네트워크·재생 가능 여부는 별도로 확인합니다.
7. 인사이트를 닫습니다. 음식점 목록과 지도가 유지되어야 합니다.
8. 음식점 별표를 누릅니다. 화면이 살짝 어두워지고 북마크 선택창이 보여야 합니다.
9. 북마크 추가하기를 눌러 광주 맛집을 만듭니다. 체크하면 음식점이 담기고 해제하면 그 북마크에서 빠져야 합니다.
10. 두 개의 북마크에 같은 음식점을 체크합니다. 두 곳에 저장되되 중복으로 추가되지 않아야 합니다.
11. 마이페이지를 누르고 틀린 비밀번호를 입력합니다. 확인창에 오류가 표시되고 북마크 화면으로 넘어가지 않아야 합니다.
12. 올바른 비밀번호를 입력합니다. 내 북마크가 보이며 광주 맛집을 누르면 목록 상단에 검색어 대신 북마크 이름이 보여야 합니다.
13. 새로고침 후 검색 상태와 저장한 북마크가 유지되는지 확인합니다. 다른 계정에서는 내 북마크가 보이면 안 됩니다.
14. 개인 정보 수정, 로그아웃, 다시 로그인과 비밀번호 재확인 흐름을 확인합니다.

## 3. 오류·작은 화면 확인

- 지역 미입력: 검색을 진행하지 않고 지역 입력을 요구합니다.
- 없는 지역·메뉴: 빈 목록과 다시 검색하기를 표시합니다.
- 공백/중복/40자 초과 북마크 이름: 저장하지 않습니다.
- 이름 입력 취소·확인창 취소·Escape: 기존 상태를 유지합니다.
- 북마크가 10개 이상일 때 선택창 안에서 목록을 스크롤할 수 있어야 합니다.
- 직접 `/#bookmarks` 또는 `/#profile` 접근: 비로그인 시 로그인, 미확인 회원은 비밀번호 확인을 요구합니다.
- PC 1440×960, 모바일 390×844: 가로 넘침 없이 목록과 인사이트를 닫고 이동할 수 있어야 합니다.
- 키보드 Tab/Enter/Escape: 검색, 별표, 체크 상자와 창 닫기에 접근할 수 있어야 합니다.
- 지도 실패: 예시 배경은 유지하고 지도 오류를 표시합니다.

## 결과

2026-10-02, 구현 적용 후 별도 테스트 단계에서 확인했습니다.

- 자동 검사: 기존 11개와 이번 8개를 합쳐 **19개 통과**, 실패 0개.
- 별도 임시 브라우저: 가입 → 로그인 → 지역 검색 → 목록 → 인사이트 → 별표 → 다중 북마크 체크·해제 → 비밀번호 확인 → 내 북마크 → 음식점 목록 흐름 통과.
- 지역만 검색 6곳, 지역·치킨 검색 1곳과 상단 검색어를 확인했습니다.
- 음식점 선택 후 기존 목록 6곳과 스크롤 위치를 유지했습니다. 예시 영상 4개, 구글 내용 3개와 외부 검색 링크를 확인했습니다.
- 영상 창 열기와 닫을 때 플레이어 해제를 확인했습니다. 외부 유튜브 스트리밍의 실제 재생 완료 여부는 검사하지 않았습니다.
- 북마크 13개에서 내부 스크롤, 여러 그룹 저장·해제, 중복 방지를 확인했습니다.
- 잘못된 비밀번호 차단, 올바른 비밀번호 통과, 직접 주소 접근 보호, 다시 로그인 후 재확인과 기존 개인 정보 화면 연결을 확인했습니다.
- 새로고침 후 북마크 이름과 목록 복원, 다른 계정의 빈 북마크 목록을 확인했습니다. 사용자의 실제 브라우저 저장소는 건드리지 않았습니다.
- PC 1440×960와 모바일 390×844에서 화면을 캡처했습니다. 모바일 가로 넘침이 없고 실제 카카오맵이 표시됐습니다.
- 브라우저 실행 오류 0개, 로컬 파일·카카오 HTTP 오류 0개. 확인 캡처는 [화면 관리 목록](SCREENS.md)에 연결했습니다.

위 결과는 자동 검사와 확인한 브라우저 흐름에 한정합니다. 상단의 나머지 오류·키보드·네트워크 실패 항목은 수동 검토 절차로 유지합니다.
