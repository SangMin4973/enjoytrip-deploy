## 1. 자동 검사

```powershell
npm test
```

기존 관광정보·회원 회귀 검사와 음식점·유튜브 검색 어댑터·저장소 검사를 실행합니다. 독립된 API 응답 테스트 데이터로 실제 필드 매핑, 음식점 제한, 페이징, 빈 결과, 실패, 시간 초과, 저장소 통합과 이전 데이터 보존을 검사합니다. 유튜브는 검색어·최대 5개·캐시·키 보호·문자 표시도 검사합니다. 자동 검사는 실시간 API 연결과 계정 권한을 확인하지 않습니다.

## 2. 실제 연결·브라우저 확인

`npm start -- --port=5179` 후 [로컬 주소](http://127.0.0.1:5179/)에서 별도 테스트 계정을 사용합니다.

1. 로그인 음식 클릭 추천이 없고 배경·로그인 입력이 유지되는지 확인합니다.
2. 지역만 검색해 실제 음식점 이름·전화·주소·지도 위치·출처를 확인합니다.
3. 지역·메뉴 검색과 다음/이전 페이지를 확인합니다.
4. 음식점·지도 핀 선택 후 목록 유지와 해당 음식점의 상세·외부 검색 링크를 확인합니다.
5. 음식점 썸네일 영역·사진 제공 없음 표시 제거, 별점 제공 없음 표시, 예시 영상·구글 본문 제거를 확인합니다.
6. 별표에서 여러 북마크에 저장·해제합니다.
7. 다른 지역 검색 후 비밀번호 확인을 거쳐 이전 북마크를 엽니다.
8. 새로고침 후 검색어·페이지와 북마크 복원을 확인합니다.
9. 유튜브의 실제 썸네일·제목·채널이 최대 5개 표시되는지 확인합니다.
10. 영상 클릭·창 닫기·음식점 변경 후 이전 영상과 결과가 남지 않는지 확인합니다.

## 3. 오류·호환·반응형 확인

- 빈 지역, 결과 없는 지역·메뉴, 전화번호 없는 장소.
- 연결 실패·시간 초과 시 더미 대체 없음, 다시 시도.
- 검색 중 화면 이동·로그아웃 시 늦은 응답이 화면을 덮어쓰지 않음.
- 회원별 북마크 분리와 기존 더미·회원 데이터 보존.
- PC·작은 화면에서 목록·페이지 버튼·인사이트 접근 가능.
- 키보드 Tab/Enter/Escape와 창 닫기.
- 지도 SDK 실패 안내와 재시도.
