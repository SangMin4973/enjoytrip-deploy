# Java 병합 정렬 성능 측정 기록

측정일: 2026-10-15 (Asia/Seoul)

- 실행 환경: win32 x64, CPU Intel(R) Core(TM) i7-14700.
- Java: Java=1.8.0_192, VM=OpenJDK 64-Bit Server VM, 최대 힙 -Xmx128m.
- 각 모드는 별도 JVM에서 실행. seed=42, 조건별 워밍업 2회, 측정 5회 중앙값.
- 모두 합성 데이터이며 외부 API·DB 호출은 0회. 결과 배열은 기준 순서와 일치하는지 검사했다.
- copy는 배열 복사만 별도 측정. sort 전체는 복사·버퍼 생성·병합 정렬을 포함하며 copy를 차감하지 않는다.
- 입력 생성·결과 검증은 시간에서 제외. 보조 공간 O(n), 관측 힙·GC 시간은 별도로 측정하지 않았다.
