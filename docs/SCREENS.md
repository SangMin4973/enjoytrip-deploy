# 맛집기행 화면 관리

## 이야기 게시판 추가 — 2026-10-05

- 맛집 검색 화면과 공통 메뉴의 게시판 링크로 `/board/list.html`에 진입합니다.
- 목록·상세·작성·수정 화면에 같은 노랑·빨강 색상, Galmuri11 폰트, 픽셀 창과 버튼을 적용했습니다.
- 목록은 최신 글부터 8개씩 표시합니다. 제목·본문·작성자로 검색하며 빈 목록과 검색 결과 없음 상태를 구분합니다.
- 모바일에서는 제목 아래 작성자·등록일·조회수를 표시합니다. 본문은 줄바꿈을 보존하고 HTML 문자는 텍스트로 표시합니다.
- 작성·수정 폼은 제목 120자, 작성자 40자, 본문 10,000자를 검증합니다. 삭제는 화면 내 확인창에서 실행합니다.
- 기존 `boards` localStorage 키와 글 번호·등록일·조회수를 유지합니다. 서버 공유와 작성자별 수정 권한은 제공하지 않습니다.

## 현재 구현 — 2026-10-02

로그인 음식 클릭 추천을 제거했습니다. 음식 낙하 배경과 드래그 동작은 유지합니다.
음식점 목록은 카카오맵 장소 검색의 실제 데이터로 연결합니다. 예시 음식점·별점·레시피 영상·구글 본문은 화면에서 제거합니다.

## 실행과 이동

`npm start -- --port=5179` 후 [로컬 화면](http://127.0.0.1:5179/)을 엽니다. 카카오 앱의 JavaScript SDK 도메인과 주소가 같아야 합니다. 회원과 북마크는 같은 브라우저·주소의 localStorage에 저장합니다.

| 화면 | 주소 | 현재 동작 |
| --- | --- | --- |
| 로그인 | `/#login` | 이메일/아이디 로그인, 음식 낙하 배경, 음식 클릭 추천 없음 |
| 회원가입 | `/#join` | 기존 로컬 회원가입 |
| 비밀번호 찾기 | `/#reset` | 기존 로컬 계정 재설정 데모 |
| 지역·메뉴 검색 | `/#home` | 지역 필수, 메뉴 선택, 전국 카카오 음식점 검색 |
| 음식점 목록 | `/#results` | 실제 이름·전화·주소·좌표, 페이지당 15곳·최대 45곳 |
| 음식점 인사이트 | 목록·지도 핀 선택 | 목록 유지, 카카오 상세·네이버·유튜브·구글 검색 링크 |
| 내 북마크 | `/#bookmarks` | 비밀번호 확인, 회원별 저장·재조회 |
| 기존 관광정보 | `/#tour` | 기존 관광정보 API·샘플 선택 화면 |
| 개인 정보 수정 | `/#profile` | 비밀번호 확인 후 기존 기능 |

검색 중 로딩, 빈 결과에 다시 검색, 실패에 오류·다시 시도를 표시합니다. API 실패 시 예시로 대체하지 않습니다. 결과는 카카오 검색 정확도 순이며 별점 추천 순위가 아닙니다. 중복 지역명은 광주광역시·경기 광주시처럼 구체적으로 입력합니다.

음식점 목록은 썸네일 없이 이름·전화번호·주소·별점 안내를 표시합니다. 사진 영역과 `사진 제공 없음` 표시는 제거했으며 목록에서 이미지 검색을 요청하지 않습니다. 사진·별점·리뷰·메뉴판·영업시간은 카카오맵 상세 페이지·외부 검색 링크로 확인합니다.

네이버·유튜브·구글은 도로명·번지를 제외한 지역명과 가게 이름을 검색어로 사용합니다(예: 해운대 국민닭바베큐). 카카오맵은 해당 장소의 상세 페이지로 이동합니다. 실제 유튜브 영상은 지역명과 가게 이름으로 조회한 썸네일·제목·채널을 최대 5개 가로 목록으로 보여줍니다. 해당 매장 방문 여부를 확정하지 않고 검색 결과라고 안내합니다.

영상 클릭 시 유튜브 재생 대화상자가 열립니다. 창 닫기·음식점 변경·화면 이동 시 플레이어를 해제합니다. 음식점을 바꾸면 이전 영상 검색 응답이 새 패널에 표시되지 않도록 취소합니다. 로딩·빈 결과·오류와 영상 다시 검색·외부 검색 링크를 제공합니다.

유튜브 키는 서버의 `.env`에서만 사용합니다. 같은 가게의 결과는 서버 메모리에서 1시간 재사용하며 서버 재시작 시 초기화됩니다. 실제 영상은 음식점 카탈로그·북마크에 저장하지 않습니다.

북마크 이름은 화면 내 대화상자에서 입력하며 1~40자·중복 이름을 검증합니다. 앱 내 브라우저에서도 사용할 수 있습니다.

## 저장과 이전 데이터

회원·세션·북마크 키는 유지합니다. 실제 음식점은 `enjoytrip.base.kakaoRestaurantCatalog`에 카카오 장소 ID로 합쳐 저장하므로 다른 지역 검색 후에도 북마크를 열 수 있습니다. 북마크에서는 저장 당시 정보임을 안내합니다.

이전 `restaurantCatalog`와 예시 ID가 담긴 북마크는 삭제하지 않습니다. 해당 음식점은 실제 목록에서 제외하고 개수를 안내합니다. 예시 ID를 실제 매장으로 임의 변환하지 않습니다. 검색 화면 새로고침 시 같은 검색어·페이지로 API를 다시 호출합니다.
