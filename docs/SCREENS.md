# 맛집기행 화면 관리

실제 프로젝트의 화면 주소와 확인할 상태를 한곳에 기록합니다. 새로운 채팅에서도 이 문서와 기존 코드를 먼저 확인하면 공통 규칙을 이어갈 수 있습니다.

## 실행과 이동

프로젝트 폴더에서 `npm start -- --port=5179`로 실행하고 http://127.0.0.1:5179/ 를 엽니다. 카카오 앱에 등록된 도메인과 같은 주소를 사용합니다.

가입한 회원과 로그인 상태는 **같은 브라우저·같은 접속 주소의 localStorage**에 저장합니다. 다른 포트나 호스트에는 자동으로 옮겨지지 않습니다. 기존 `enjoytrip.base.*` 저장 키와 회원 데이터를 유지합니다.

| 번호 | 화면 | 주소 | 현재 범위 | 확인할 상태 |
| --- | --- | --- | --- | --- |
| 01 | 첫 로그인 | `/#login` 또는 비로그인 상태의 `/` | 노랑·빨강 픽셀 디자인 확정, 회원 로그인 연결 | 기본, 입력 오류, 비밀번호 보기, 로그인 중, 음식 클릭 추천, 모바일 |
| 02 | 회원가입 | `/#join` | 기존 기능 연결, 디자인 검토 예정 | 입력 검증, 중복 회원, 가입 성공 → 로그인 |
| 03 | 비밀번호 찾기 | `/#reset` | 기존 로컬 계정 재설정, 디자인 검토 예정 | 계정 불일치, 확인 불일치, 재설정 성공 → 로그인 |
| 04 | 관광정보 조회 | `/#tour` | 로그인 후 진입하는 기존 화면, 디자인 검토 예정 | 지역 선택, 목록, 로딩, 빈 결과, 오류, 상세, 페이지 이동 |
| 05 | 내 정보 | `/#profile` | 기존 기능 연결, 디자인 검토 예정 | 조회, 수정, 로그아웃, 탈퇴 |

관광정보·내 정보 주소로 비로그인 접근하면 로그인 화면으로 이동합니다. 로그인한 사용자는 새로고침 후 기존 화면을 이어갑니다. 로그아웃과 탈퇴 후에는 로그인 화면으로 돌아갑니다.

## 확정된 로그인 표현

- 서비스명: 맛집기행.
- 주색: 노랑 `#ffdf70`, 빨강 `#df402c`, 진한 빨강 `#a42b21`.
- 글꼴: 로컬 Galmuri11, 네모 테두리와 픽셀 그림자.
- 배경: 카카오맵 불투명도 30%, 75초 주기로 천천히 이동. 지도 로딩 실패 시 도트 지도 이미지 표시.
- 음식: 사용자 제공 PNG 11종, PC 14개·모바일 7개. 아래로 계속 떨어지며 바닥에 쌓이지 않음.
- 음식 클릭·터치·키보드 Enter/Space: 랜덤 한 끼 추천. 별도 추천 버튼과 데모 조작 UI 없음.
- 로그인: 이메일 또는 기존 아이디 허용. 비밀번호 보기, 회원가입·비밀번호 찾기 링크 포함.
- 회원정보와 로그인 세션은 localStorage 사용. 비밀번호는 기존 PBKDF2 해시 방식 유지.
- 로그인 상태 유지 선택 시 30일, 미선택 시 12시간 후 만료. 만료는 새로고침·화면 이동 시 확인. 기존 만료 정보가 없는 세션도 호환.

## 화면별 검토 방법

1. Figma에서는 전체 화면과 이동 흐름을 한 파일에 모읍니다. 각 화면에 번호를 붙이고 기본·오류·로딩·모바일 상태를 함께 둡니다.
2. 채팅은 기능 단위로 묶습니다. 예: 회원(로그인·가입·재설정), 맛집 탐색(검색·목록·상세), 여행 계획(선택·순서·저장).
3. 색상·글꼴·공통 버튼·저장 키를 바꾸면 관련 코드와 이 문서를 함께 수정합니다.
4. 디자인을 확정하기 전에 실제 프로젝트 미리보기에서 클릭, 저장, 새로고침, 모바일 동작을 확인합니다.

Figma 흐름 기능 안내: https://help.figma.com/hc/en-us/articles/360039823894-Create-and-manage-prototype-flows

현재 Figma 파일이나 새 채팅은 생성하지 않았습니다. 자연어 맛집 추천·여행 루트 등 기획 화면은 구현될 때 목록에 추가합니다.

## 이번 연결의 확인 결과 — 2026-10-02

- 자동 테스트 11개 통과. 기존 필터·관광 API 오류 처리·회원 기능 검사 포함.
- PC 1440×960, 모바일 390×844 확인. 가로 넘침 없음, 로컬 픽셀 글꼴과 음식 이미지 로드 정상.
- 실제 카카오맵 준비 완료, 지도 타일 36개 로드. 배경 불투명도 30%와 음식 무한 재생성 확인.
- 회원가입 → 이메일/아이디 로그인 → 관광정보 조회, 내 정보 수정, 새로고침, 다른 탭 로그아웃 반영, 재설정, 세션 만료, 탈퇴 확인.
- 기존 샘플 관광 목록·상세 조회 연결 확인. 로그인·회원 작업은 서버로 쓰기 요청을 보내지 않음.
- 음식 마우스 클릭·키보드 추천, 동작 줄이기 환경과 지도 SDK 한 번 로드 확인.
- 검사 브라우저의 실행 오류와 지도·로컬 파일 요청 오류 없음. 검사 계정은 별도 임시 브라우저에서만 사용.
