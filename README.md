# 맛집기행 프론트엔드

EnjoyTrip Web(Front) 명세서의 **필수 기능만** 구현한 HTML·CSS·Vanilla JavaScript 프로젝트입니다. 첫 로그인 화면에는 확정한 맛집기행 픽셀 디자인을 적용했습니다. 다른 화면은 기존 Bootstrap 기본 폼과 표를 유지합니다.

맛집 여행 프로젝트의 자연어 추천·인사이트·여행 루트 기능은 기획 문서에만 정리했습니다.

## 확정한 첫 로그인 화면

프로젝트 폴더에서 다음 명령으로 실행하면 카카오 앱에 등록된 주소에서 확인할 수 있습니다.

```powershell
npm start -- --port=5179
```

[http://127.0.0.1:5179/](http://127.0.0.1:5179/) 를 엽니다. 비로그인 첫 진입은 로그인 화면이며, 회원가입 후 이메일 또는 기존 아이디로 로그인하면 관광정보 조회 화면으로 이동합니다. 로그인 세션이 있으면 기존 화면을 이어갑니다.

- 노랑·빨강 레트로 창과 로컬 Galmuri11 글꼴, 투명 음식 PNG 11종을 적용했습니다.
- 연한 카카오맵 위로 PC 14개·모바일 7개의 음식이 계속 떨어집니다. 바닥에 쌓이지 않습니다.
- 음식 아이콘을 잡으면 랜덤 추천이 표시됩니다. 별도 추천 버튼과 데모 설명은 없습니다.
- 로그인 상태 유지 선택 시 30일, 미선택 시 12시간 동안 localStorage 세션을 유지합니다. 새로고침·화면 이동 시 만료를 확인합니다.
- 회원 데이터·세션은 기존 `enjoytrip.base.*` localStorage를 사용하며 비밀번호는 기존 PBKDF2 해시로 저장합니다. 서버 인증이나 DB를 추가하지 않았습니다.
- 화면을 벗어나면 음식 모션과 지도 이동이 쉬고, 동작 줄이기 설정에서도 모션을 정지합니다.

화면 주소와 검토 상태는 [화면 관리 목록](docs/SCREENS.md)에 정리했습니다. 로그인 디자인은 `css/login.css`, 음식·지도 모션은 `js/login-scene.js`에 있어 이후 화면 작업과 구분할 수 있습니다.

## 실행

Node.js 22 이상에서 실행합니다. 추가 패키지 설치는 필요하지 않습니다.

```powershell
npm start
```

[http://localhost:5173](http://localhost:5173)을 엽니다. 종료는 터미널에서 `Ctrl+C`를 누릅니다.

서비스키가 설정되어 있으면 **실제 관광 API** 모드로 시작합니다. 키가 없으면 샘플 모드로 시작하며 서울·부산·제주의 가상 관광정보와 회원 기능을 확인할 수 있습니다. HTML 파일을 더블클릭하거나 Live Server로 실행하지 말고 `npm start`의 로컬 서버를 사용해 주세요.

## 구현 범위

| 요구사항 | 구현 |
| --- | --- |
| F101 지역별 관광정보 수집·조회 | 시도·시군구 선택, 한국관광공사 API 연결 코드, 샘플 모드 |
| F102 관광지·숙박·음식점 조회 | 유형 필터, 목록, 상세 조회 |
| F103 문화시설·공연·여행코스·쇼핑 조회 | 유형 필터, 목록, 상세 조회 |
| F107 회원 관리 | 가입, 내 정보 조회, 이름·이메일·비밀번호 수정, 탈퇴 |
| F108 로그인 관리 | 로그인, 로그아웃, 비밀번호 재설정 데모 |

레포츠 조회도 같은 유형 필터에 포함합니다. 페이지 이동, 로딩, 빈 결과, 오류 표시와 폼 입력 검증을 제공합니다.

**미구현:** 자연어 맛집 추천, AI, 유튜브·리뷰 인사이트, 여행 경로 저장, hotplace, 뉴스 크롤링, 공지사항·게시판.

## 실제 API 설정

1. `.env.example`을 `.env`로 복사합니다.
2. 공공데이터포털의 한국관광공사 국문 관광정보 서비스 활용 신청 후 `TOUR_API_SERVICE_KEY`에 서비스키를 입력합니다. Decoding 키를 권장합니다.
3. 서버를 다시 시작합니다.
4. 화면의 데이터 선택을 **실제 관광 API**로 바꿉니다.

```powershell
Copy-Item .env.example .env
```

첨부된 **국문 관광정보 개방데이터 활용매뉴얼 Ver 4.4 (2026-02-10)** 기준으로 `KorService2`를 사용합니다. 이 버전에서 삭제된 `areaCode2` 대신 `ldongCode2`의 법정동 지역코드를 사용합니다.

| 기능 | 외부 API |
| --- | --- |
| 시도·시군구 | `ldongCode2` |
| 지역·유형별 목록 | `areaBasedList2` |
| 검색어가 있는 목록 | `searchKeyword2` |
| 상세 정보 | `detailCommon2` |

키가 없거나 API가 실패하면 오류를 표시합니다. 실제 모드에서 샘플 데이터로 자동 대체하지 않습니다.

### 연결 오류 확인

매뉴얼의 XML 인증 오류와 게이트웨이의 JSON 인증 오류를 모두 읽어 실제 오류코드를 표시합니다. HTTP 403으로 응답해도 본문에 있는 인증 오류를 우선 확인합니다.

| 오류 | 의미 | 확인할 내용 |
| --- | --- | --- |
| 30 | 등록되지 않은 서비스키 | `.env`의 키를 발급받은 값과 정확하게 비교하고 서버 재시작 |
| 20 | 서비스 접근 거부 | 국문 관광정보 서비스_GW 활용 신청 및 승인 상태 |
| 22 | 요청 한도 초과 | 일일 요청량 및 할당량 |
| 31 | 활용 기간 만료 | 활용 기간 연장 신청 |
| 32 | 등록되지 않은 IP | 활용 신청의 허용 IP 설정 |

신규 활용 신청 후 반영 시간이 필요할 수 있습니다. 발급 키에 문자를 임의로 추가하거나 삭제하지 말고 정확한 값을 사용하세요. 채팅이나 Git에 키를 올릴 필요는 없습니다.

연결 장애의 원인은 기존 서비스키에 불필요한 앞 문자가 포함되어 제공자가 HTTP 403 / 오류 30을 반환한 것이었습니다. 사용자가 다시 제공한 정확한 키로 수정한 후 실제 시도 16개, 서울 시군구 25개, 종로구 음식점 목록(총 185건), 상세 정보와 한글 검색을 정상 조회했습니다. 키는 `.env`에만 저장합니다.

지도는 선택 기능입니다. `.env`의 `KAKAO_MAP_JS_KEY`를 설정하고 카카오 앱의 웹 도메인에 `http://localhost:5173`을 등록하면 조회 결과 좌표를 지도에 표시합니다. 지도 SDK 이용 권한과 등록 도메인은 [카카오 공식 가이드](https://apis.map.kakao.com/web/guide/)를 확인해 주세요. 지도 실패 시 목록 조회는 계속 동작합니다.

카카오 앱의 JavaScript SDK 도메인에 `http://127.0.0.1:5179`와 확정 화면의 호스팅 주소가 등록되어 있습니다. 위 로그인 미리보기 명령으로 등록된 로컬 주소를 사용합니다. 기존 기본 주소 `http://localhost:5173`을 쓰려면 그 주소도 해당 앱에 등록되어 있어야 합니다.

`server.mjs`는 로컬 실행과 관광 API 키 중계만 담당합니다. 서비스키는 브라우저로 전달하지 않습니다. 카카오 JavaScript 키는 지도 SDK를 위해 브라우저에 전달되는 키입니다. `.env`는 커밋 대상에서 제외되어 있습니다.

## 회원 기능의 범위

- 회원정보는 현재 브라우저의 `localStorage`에 저장합니다.
- 비밀번호는 랜덤 salt와 PBKDF2 해시로 저장하며 평문으로 저장하지 않습니다.
- 로그인 상태는 새로고침 후 유지됩니다. 같은 서버 주소의 다른 탭에도 변경을 반영합니다.
- 비밀번호 찾기는 가입한 아이디·이메일을 확인하고 새 비밀번호를 설정하는 **실습용 데모**입니다. 메일 발송과 본인 인증은 없습니다.
- 서버 인증·DB·권한 검증은 구현하지 않았습니다. 실제 서비스에서는 서버 인증으로 교체해야 합니다.
- 다른 브라우저나 다른 접속 주소에서는 계정이 공유되지 않습니다. 실제 쓰는 비밀번호는 입력하지 마세요.

```text
resources/                 기존 리소스 (보존)
```

## 기능 확인 순서

1. 샘플 모드에서 서울 → 종로구 → 음식점을 선택하고 조회합니다.
2. 상세 보기를 열어 가상 정보와 출처 표시를 확인합니다.
3. 전체 유형 조회와 다음/이전 페이지를 확인합니다.
4. 첫 로그인 화면에서 회원가입 후 로그인하고, 관광정보 조회와 내 정보 수정을 확인합니다.
5. 새로고침, 로그아웃, 비밀번호 재설정, 다시 로그인, 탈퇴를 확인합니다.
6. 실제 모드에서는 유효한 API 키를 설정한 뒤 동일한 조회를 확인합니다.

```powershell
npm test
```

검증 결과: 자동 테스트 11개 통과. 회원·샘플 기능, 매뉴얼의 요청 파라미터, JSON/XML 인증 오류, 키 누락과 시간 초과를 확인했습니다. 수정한 키로 실제 시도·시군구·음식점 목록·상세·한글 검색도 정상 조회했습니다. 브라우저에서도 실제 음식점 조회·상세·다음 페이지·한글 검색이 정상 동작했습니다. 등록된 로그인 미리보기 주소에서 실제 카카오맵과 지도 타일 36개를 확인했습니다. 회원가입, 이메일·아이디 로그인, 새로고침, 다른 탭의 로그아웃 반영, 수정·재설정·탈퇴와 기존 샘플 목록·상세 조회도 브라우저에서 확인했습니다.
