# 맛집기행 프론트엔드

HTML·CSS·Vanilla JavaScript 기반 EnjoyTrip 실습 프로젝트입니다. 로그인 이후 지역·메뉴로 실제 음식점을 검색하고, 지도·외부 정보·개인 북마크를 함께 이용합니다.

## 실행

Node.js 22 이상이 필요합니다. 추가 패키지 설치는 없습니다.

```powershell
npm start -- --port=5179
```

[http://127.0.0.1:5179/](http://127.0.0.1:5179/)을 엽니다. HTML 더블클릭이나 Live Server 대신 프로젝트 서버를 사용합니다. 기본 `npm start`는 `.env`의 PORT 또는 5173을 사용합니다. 카카오 앱에 등록한 도메인과 브라우저 주소가 정확히 같아야 합니다.

## 이번 변경 — 2026-10-02

- 로그인 음식 클릭 추천을 제거했습니다. 음식 낙하 배경·드래그·픽셀 디자인은 유지합니다.
- 음식점 더미 목록을 카카오 장소 검색으로 교체했습니다. 지역은 필수, 메뉴는 선택입니다.
- 실제 이름·주소·전화·좌표·카테고리와 지도 핀을 표시합니다. 전화번호가 없으면 미등록으로 표시합니다.
- 검색 정확도 순으로 페이지당 15곳, 최대 45곳을 조회합니다. 로딩·빈 결과·오류·다시 시도와 페이지 이동을 제공합니다.
- 사진 칸은 Google 이미지 검색의 첫 결과를 사용하며, 설정·결과가 없거나 이미지 로딩에 실패하면 제공 없음으로 표시합니다. 별점은 제공 없음으로 표시합니다. 예시 영상·구글 본문은 제거했습니다.
- 인사이트는 카카오맵 상세 페이지, 지역명과 가게 이름을 사용하는 네이버·유튜브·구글 검색 링크로 구성합니다.
- 지역명과 가게 이름으로 검색한 실제 유튜브 영상의 썸네일·제목·채널을 최대 5개 표시합니다. 클릭하면 재생창이 열리고 닫으면 재생을 종료합니다.
- 카카오 장소 ID로 음식점 정보를 저장하여 다른 검색 후에도 북마크를 다시 열 수 있습니다.

검색 순서는 별점 기반 추천이 아닙니다. 카카오 공개 장소 검색 API는 사진·별점·리뷰·상세 메뉴·영업시간·영상을 제공하지 않습니다. 자세한 정보는 장소 상세 페이지에서 확인합니다. [카카오 장소 검색 문서](https://developers.kakao.com/docs/ko/local/dev-guide#search-by-keyword), [지도 장소 검색 문서](https://apis.map.kakao.com/web/documentation/#services_Places)

## 카카오맵 설정

기존 `.env`가 있으면 보존하고 필요한 값만 수정합니다. 새 환경에서는 `.env.example`을 복사한 뒤 설정합니다.

```powershell
Copy-Item .env.example .env
```

1. `KAKAO_MAP_JS_KEY`에 카카오 앱의 **JavaScript 키**를 넣습니다. REST/Admin 키를 넣지 않습니다.
2. 카카오 앱의 JavaScript SDK 도메인에 `http://127.0.0.1:5179`를 등록하고 지도 API 이용 권한을 확인합니다.
3. 서버를 다시 시작합니다. 키는 `/api/config`로 브라우저에 전달됩니다.

같은 키로 SDK의 `services.Places.keywordSearch`를 사용하며 음식점 카테고리 `FD6`으로 제한합니다. 추가 REST 키나 별도 서버 API는 필요하지 않습니다. 지도 SDK는 로그인·음식점·관광정보 화면에서 공유합니다. 도메인·권한·한도·네트워크 문제로 검색이 실패하면 오류를 표시하며 예시 데이터로 대체하지 않습니다.

## 유튜브 설정

기존 `.env`에 `YOUTUBE_API_KEY`를 추가하고 서버를 다시 시작합니다. Google Cloud에서 **YouTube Data API v3**가 활성화되어 있어야 합니다. 키는 서버에서만 사용하며 `/api/config`나 프론트엔드에 전달하지 않습니다. 서버에서 호출하므로 웹사이트 HTTP 리퍼러 제한 대신 서버에 맞는 키 제한을 사용합니다.

`/api/youtube/search?q=지역명+가게이름`이 실제 영상 검색을 중계합니다. 영상만 최대 5개, 임베드 가능 조건으로 조회하며 성공·빈 결과를 서버 메모리에 1시간 보관합니다. 같은 가게의 동시 요청도 공유합니다. 실패는 캐시하지 않고 오류·다시 검색과 외부 유튜브 링크를 제공합니다. 캐시는 서버 재시작 시 초기화됩니다.

검색된 영상이 해당 지점의 방문 영상이라는 보장은 없습니다. 이름이 같은 다른 매장이나 관련 영상이 포함될 수 있으며 재생 가능 여부도 제공자에 따라 달라질 수 있습니다. [YouTube 검색 문서](https://developers.google.com/youtube/v3/docs/search/list)

## 음식점 이미지 설정

`.env`에 `GOOGLE_CUSTOM_SEARCH_API_KEY`와 `GOOGLE_CUSTOM_SEARCH_CX`를 추가하고 서버를 재시작합니다. cx는 이미지 검색을 켠 Programmable Search Engine의 검색엔진 ID입니다. 두 값은 서버에서만 사용합니다.

`/api/restaurant-image?q=지역명+가게이름`은 `searchType=image`, `num=1`로 첫 결과를 조회합니다. 목록에서 화면에 들어온 음식점만 최대 2건씩 요청하고 결과를 서버 메모리에 24시간 보관합니다. API 실패는 캐시하지 않습니다. 목록·화면 변경 시 요청을 취소하고 이미지는 북마크에 저장하지 않습니다. 첫 결과의 썸네일을 사용하고 `검색 이미지`로 표시합니다. 해당 매장의 공식 사진임을 보장하지 않습니다.

Google Custom Search JSON API는 신규 이용을 제한하고 기존 이용은 2027-01-01까지 지원합니다. 키를 재발급해도 프로젝트 이용 제한은 해결되지 않을 수 있습니다. [Google 공식 안내](https://developers.google.com/custom-search/v1/overview)

## 화면·저장

`/#login` → 로그인 → `/#home` 검색 → `/#results` 목록·인사이트·별표 저장 → 비밀번호 확인 → `/#bookmarks` 재조회입니다. 개인 정보 수정은 `/#profile`, 기존 관광정보는 `/#tour`입니다.

회원·세션·북마크는 동일 브라우저·동일 접속 주소의 localStorage에 저장됩니다. 다른 컴퓨터·브라우저·포트로 자동 이전되지 않습니다. 회원별 북마크 분리, 여러 그룹에 중복 없는 저장·해제, 비밀번호 재확인 흐름을 유지합니다.

실제 카탈로그는 `enjoytrip.base.kakaoRestaurantCatalog`에 저장합니다. 새 검색에서 이전 장소를 덮어 삭제하지 않고 ID로 합칩니다. 북마크는 저장 당시 정보이며 최신 정보는 카카오맵에서 확인합니다. 검색 화면 새로고침 시 API를 다시 호출합니다.

이전 예시 카탈로그와 예시 ID가 담긴 북마크는 삭제하지 않습니다. 예시 음식점은 실제 결과에서 제외하며 개수를 안내합니다. 기존 예시를 실제 매장으로 임의 연결하지 않습니다.

## 기존 EnjoyTrip 기능

| 요구사항 | 구현 |
| --- | --- |
| F101 지역 관광정보 | 시도·시군구, 한국관광공사 실제 API·샘플 선택 |
| F102 관광지·숙박·음식점 | 유형별 목록·상세 |
| F103 문화시설·행사·여행코스·쇼핑 | 유형별 조회, 레포츠 포함 |
| F107 회원 관리 | 가입·조회·수정·탈퇴 |
| F108 로그인 관리 | 로그인·로그아웃·비밀번호 재설정 데모 |

관광정보는 `TOUR_API_SERVICE_KEY`를 설정하고 `/#tour`에서 실제 모드를 선택합니다. 공공데이터포털 국문 관광정보 서비스_GW 승인 키를 사용하며 Decoding 키를 권장합니다. 서비스키는 서버에서만 사용합니다. 실제 모드는 오류 시 샘플로 대체하지 않습니다.

관광 API는 제공받은 Ver 4.4 매뉴얼에 맞춰 `KorService2`의 `ldongCode2`·`areaBasedList2`·`searchKeyword2`·`detailCommon2`를 사용합니다. 인증 오류 30은 키 불일치, 20은 접근 거부, 22는 한도 초과, 31은 기간 만료, 32는 IP 설정을 확인합니다.

## 회원 기능의 범위

회원 데이터는 기존 `enjoytrip.base.*` 키를 유지합니다. 비밀번호는 salt와 PBKDF2 해시로 저장합니다. 로그인 유지 선택 시 30일, 미선택 시 12시간이며 새로고침·화면 이동 시 만료를 확인합니다. 다른 탭 변경도 반영합니다.

회원 인증 서버·DB·메일 발송·본인 인증은 없습니다. 비밀번호 찾기는 로컬 계정 재설정 데모입니다. 실습용 비밀번호를 사용하세요.

자연어·AI 추천, 리뷰 수집, 여행 경로 편집·저장은 후속 기획입니다.
